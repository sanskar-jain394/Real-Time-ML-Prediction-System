# Real-Time-ML-Prediction-System
Real-Time Machine Learning Prediction System using Streamlit and Linear Regression. This project predicts house prices based on user inputs like area and number of bedrooms. The model is trained using Scikit-learn and deployed as a real-time web application using Streamlit.

# 🏠 Real-Time ML Prediction System

A Machine Learning web application built using Python, Scikit-learn, and Streamlit that predicts house prices in real time based on user input.

---

# 🚀 Features

✅ Real-time prediction  
✅ Simple and user-friendly interface  
✅ Machine Learning based system  
✅ Streamlit web application  
✅ Instant prediction results  
✅ Saved ML model using Joblib

Install required libraries:


# ▶️ Run the Project

Run the Streamlit application:

```bash
streamlit run app.py
```

---

# 💡 How It Works

1. Dataset is created  
2. ML model is trained  
3. Model is saved using Joblib  
4. Streamlit loads the saved model  
5. User enters input  
6. System predicts house price instantly
